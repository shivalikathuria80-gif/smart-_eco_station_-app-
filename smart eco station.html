    Core system modules

    Dual-Node Hardware Architecture

    By separating heavy visual processing from core mechanical timing, the system achieves maximum stability:

    • Master Node (ESP32-DevKit): Manages RFID reader, LCD I2C, solenoid locking, servo PWM, and Wi-Fi requests.
    • Vision Node (ESP32-CAM): Handles snapshot capture, LED flash illumination, and UART serial output.
    ESP32 30-Pin ESP32-CAM UART 115200 SPI / I2C

    Anti-Farming Security Protocols

    Built-in hardware and software guardrails prevent users from exploit-farming reward points without proper disposal:

    • Physical Lock: Solenoid remains locked until a valid RFID card is swiped.
    • Visual Verification: Camera validates object presence before triggering servo or points payload.
    12V Solenoid Session Locking

    Realtime Web Infrastructure

    Zero page refreshes required. The dashboard updates live via web sockets:

    • Firebase REST API: ESP32 sends HTTPS requests over Wi-Fi (server-side increments for points, PATCH for bin levels).
    • Event Listeners: Client dashboard uses JavaScript on('value') listeners for zero-latency point feedback.
    • Leaderboard Engine: Auto-sorts user metrics dynamically as scores update.
