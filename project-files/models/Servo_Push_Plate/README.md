# How one servo pushes the plate down

Open `servo_crank_viewer.html` (works offline). Left = servo lying flat, right = servo on its side.

- A servo only turns. The tip of its arm always moves in a CIRCLE (the red ring).
- Servo lying flat: the circle lies flat, so the tip only goes left/right. The plate never moves.
- Servo on its side (shaft pointing at you, like a wheel): the circle stands up, so the tip goes UP and DOWN.
- A push rod (170 mm) hangs from the arm tip to the plate. Two guide rods keep the plate level.
- Servo 0 deg = plate up. Servo 180 deg = plate down. Plate travel = 2 x arm length (60 mm arm = 120 mm).

Note: a longer arm means more travel but less push. An SG90 with a 60 mm arm pushes only about 300 g, so it can show the movement but won't squash much. An MG90S pushes a bit more.
